# GT Coding - Next.js CRUD App

GT Coding is a simple and efficient CRUD (Create, Read, Update, Delete) web application built using Next.js. It allows users to manage topics with associated time schedules in a clean and user-friendly interface.

Live Demo: https://daily-task-allocation.vercel.app/


##  Features

-  Add new topics with time
-  View all topics
-  Edit/update existing topics
-  Delete topics
-  Real-time UI updates
-  Clean and minimal UI design

---

##  Tech Stack

- **Framework:** Next.js (App Router)
- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Backend:** Next.js API Routes
- **Database:** MongoDB (Mongoose)
- **Deployment:** Vercel
